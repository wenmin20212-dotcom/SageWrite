Windows运行环境需要PowerShell、Pandoc；05c-pdf需要Microsoft Word COM。AI写作和审计需要自行配置有效凭据。04R的核验标记必须来自真实人工或编辑审查，程序不会自动证明文献或模型有效。

不要用reset --hard覆盖当前工作目录。需要回到此版时，从GitHub单独检出到新目录：

```powershell
git clone --branch sagewrite-ps1-20260915 --single-branch https://github.com/wenmin20212-dotcom/SageWrite.git SageWrite-ps1-20260915
cd SageWrite-ps1-20260915/engine
```

具体命令参数以各脚本param声明和04R-README.md为准。使用者需另外恢复自己的书籍工作区；程序标签不备份书稿。
