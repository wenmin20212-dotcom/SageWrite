# 03RW: chapter-by-chapter language revision

Run with Windows PowerShell 5.1 or later. Defaults to the adjacent `../book`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\03RW.ps1 -CheckOnly
powershell -NoProfile -ExecutionPolicy Bypass -File .\03RW.ps1 -Chapter 1
powershell -NoProfile -ExecutionPolicy Bypass -File .\03RW.ps1 -StartChapter 2 -EndChapter 5
powershell -NoProfile -ExecutionPolicy Bypass -File .\03RW.ps1 -All
```

Optional `-BookRoot` selects a book directory; `-BookName` uses the existing
SAGEWRITE_WORKSPACE_ROOT convention and takes precedence. `-SpecPath` selects a
different writing specification. Default: `00_brief/writing_spec.md`.
Input must have one `##` heading per chapter in `01_outline/toc.md`, with matching
`#` headings in `02_chapters/01.md`, `02.md`, etc. Section-based books must first
be assembled into chapter files. CheckOnly validates without files or model calls.

Model configuration is delegated to `00-llm.ps1`: SAGE_LLM_PROVIDER,
SAGE_LLM_MODEL, SAGE_LLM_API_STYLE, SAGE_LLM_BASE_URL, SAGE_LLM_ENDPOINT,
SAGE_LLM_API_KEY and the existing Codex command/work-directory settings.
`-Model` optionally overrides the model for providers that accept an explicit model.
The repository default `codex_agent` mode writes a request under
`logs/agent_requests`, emits `SAGE_AGENT_PENDING`, and waits for the active agent
handoff workflow described in `LLM-CONFIG.md`. The separate `codex` provider starts
the configured CLI. API providers use their configured endpoint and credentials.
No credentials are stored in revision reports.

`03_rewrite/original` holds the first-run backup and its hashes are recorded in
`manifest.json`. Revised chapters go to `03_rewrite/chapters`; review notes and
per-chapter checkpoints go to `03_rewrite/review`. Repeat the same command to
resume: completed drafts are skipped; a draft whose audit failed is reused for
the audit. Failed generation is retried on the next invocation. Execution stops
on an error. Do not edit incomplete drafts during recovery.

Original/spec/TOC changes stop continuation. To intentionally start a different
revision, preserve and move the entire `03_rewrite` directory aside first.
No force-overwrite option is provided. A filesystem lock prevents concurrent runs.

Every result remains `needs_human_review`. Heading checks, length warnings and
model audits cannot prove that facts or plot are unchanged. Review each chapter
against the original and check consistency across chapters before manually
promoting revisions into the book and running the 05 PDF pipeline. This program
never replaces source chapters or generates a PDF automatically.
