# Codex语音写书：九步操作说明

作者可以用语音与Codex讨论、审阅和确认，Codex负责读取文件、调用SageWrite及检查结果。不必手动逐条输入命令。前提是当前Codex客户端支持语音输入，Agent能够访问本机工作区，且运行依赖已配置；软件登录、安装权限和外部平台认证仍可能需要用户完成。SageWrite本身不提供语音识别。

| 步骤 | 工作与程序 | 主要文件 | 可以这样说 |
| --- | --- | --- | --- |
| 1. 建立项目 | 讨论书名、读者、思想、风格、字数；01-intake建立工作区。00-common是公共库，不是独立创作步骤 | 00_brief/objective.md | 我要写一本关于……的书，先讨论定位，再建立工作目录。 |
| 2. 制定目录 | 02-structure生成目录，必要时02b-expand细化，再由作者定稿 | 01_outline/toc.md | 按定位生成全书目录，写清每节重点和字数，先不写正文。 |
| 3. 逐节写作 | 03-write按目录逐个写作单元生成；随时讨论精修 | 02_chapters/01.md、02.md…… | 开始写第一节，完成后报告字数，等我确认再继续。 |
| 4. 编辑审读 | 04B33形成逐节意见，04C44执行批准的返修；外部审计可经04c2、04c3处理，按任务选择，不全部依次运行 | 审读报告、修改JSON、修订MD、back备份 | 先审读这一章，列出问题和方案，我确认后再改。 |
| 5. 引用核验 | 04R管理引用；04Reference2记录Agent实际查证；04Reference3执行批准的来源字段修订；正文修订仍走04R审核计划 | references.md、reference_state.json、证据及报告 | 检查来源是否真实、能否支持正文，并留下核验记录。 |
| 6. 封面与插图 | Agent或相应封面入口生成素材，保存到本书工作区，在MD中插入链接 | cover.png、03_assets中的图片 | 画一张模型图，插入这一节对应位置。 |
| 7. 格式检查 | 04F Check检查标题、文件映射、图片和引用；需要规范化时先备份再Normalize | 格式报告及绑定当前文件的通过标记 | 先检查全书格式，通过后再排版。 |
| 8. 导出成书 | 05c-pdf生成PDF，05b-epub生成EPUB，检查实际成品 | 04_output/zh中的PDF、EPUB | 用当前书稿生成新版PDF和EPUB，保留原封面。 |
| 9. 备份锁版 | 明确版本名及范围，保存源稿、图片、报告和成品；程序和书稿可分别锁版 | 备份、Git提交、版本标签或Release | 把这一版锁定，完整备份；上传前先确认仓库可见性和范围。 |

## 操作约定

- toc.md中的每个三级标题（###）是一项写作单元，对应一个数字MD。01.md可能是前言，不一定是第一章。
- 每节先确认思想和边界，再写正文；审核时检查重复、术语和相邻章节衔接。
- 修改前备份，不覆盖唯一原稿。目录调整须同步正文映射、插图与跨章引用。
- 文献存在不等于支持正文；摘要不等于全文，风险筛查不等于逐条全文核验。
- 修改正文、目录、图片或参考文献后重新检查。05不得绕过04F审批标记。
- Agent报告文件路径、字数、修改范围和未完成项，不能只说“已完成”。
- 不同设备运行同一版本仍可能因字体、Word版本而改变页数，需检查实际PDF。

完整流程：语音讨论 → 固定大纲 → 逐节写作 → 审读修改 → 文献核验 → 排版检查 → 导出成书 → 锁版保存。

详细参数和前置条件见[Agent调用手册](AGENT-CALLING-GUIDE.md)，环境准备见[环境恢复清单](ENVIRONMENT-RESTORE.md)。
