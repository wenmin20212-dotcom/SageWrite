# SageWrite UAH 1.1.0

独立 SageWrite 仓库首次提供 UAH v0.2 Agent 安装包，包内不包含 BOSS。发布包包含 Windows x64 Node 24.21.0、8 个 Skill、40 个 MCP 工具、项目回执适配、安装脚本、写作模型配置向导、BOM 与文档。

安装：校验 SHA256，解压到独立目录，运行启动安装.cmd，在纯 UAH 中选择目录，再分别配置 UAH 对话模型与 SageWrite 写作模型。

验收：UAH 清单校验、MCP 工具声明与实际工具一致、独立工作区建书、中文目标文件、缺少写作模型时明确错误。发布验收不包含真实模型正文生成、Word/PDF/出版上传；这些取决于用户模型凭据与本机依赖。对话历史、重启恢复与 UI 项目登记仍需纯 UAH 的交互验收。

数据：包不携带原有书籍、开发仓库、聊天历史或凭据。安装会生成本机路径，移动目录后重新运行安装。当前 UAH 不自动继承写作模型配置。
